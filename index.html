Oracle documentation Select AI Agent Agent workflow capability used to expose approved tools and actions through Autonomous AI Database. Database Performance

Automatic Indexing Database-managed analysis and implementation of indexes based on workload evidence. Oracle documentation Automatic Partitioning Managed recommendations and operations for partitioning large tables where partition pruning can improve access. Oracle documentation Compression Table and storage techniques that reduce data footprint and can reduce scan I/O for suitable workloads. Oracle documentation Optimizer Statistics Metadata about table, column, and index data distribution used by the optimizer to estimate execution costs. Oracle documentation SQL Plan Management Controls and baselines used to reduce SQL execution plan regressions. Oracle documentation

Operations and Integration

Oracle documentation Capacity Planning Estimating future CPU, storage, and workload requirements from current usage and growth patterns.
