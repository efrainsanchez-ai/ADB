Ask Oracle Chatbot Powered by Select AI

Ask Oracle is a sample Oracle APEX chatbot application that uses Autonomous AI Database Select AI profiles and Select AI Agents to provide a ready-to-use interface for LLM chat, natural language to SQL, retrieval augmented generation, charts, and task-oriented agent workflows.

What it is

Ask Oracle is a sample APEX application for Autonomous AI Database that turns Select AI capabilities into a chatbot user experience. It uses configured AI profiles and Select AI Agent definitions so users can ask questions, inspect generated SQL, create charts from result sets, use RAG-backed profiles, and work with agent teams from a browser-based interface.

Ask Oracle Interaction Flow
User Prompt Chat, data question, chart request, RAG question, or agent task.
APEX Chat UI Conversation history, settings, prompt details, SQL display, and chart controls.
Select AI AI profile routes chat, NL2SQL, narration, and RAG actions.
Agent Team Select AI Agents handle approved task workflows and tools.
Results Answers, SQL, result sets, charts, explanations, and narrated output.

Color guide: blue-accent cards highlight interface or result signals, gray-accent cards highlight agent or tool decisions, and plain cards show the normal chatbot interaction flow.

Capability What Ask Oracle provides What to validate
Chat Conversation with the LLM configured in the selected AI profile. The selected profile points to an approved model provider or private model.
NL2SQL Natural-language questions converted into SQL against Autonomous AI Database. Generated SQL is visible, scoped, and uses only intended schemas or objects.
RAG Answers grounded by the vector index configured in the selected AI profile. Profiles with vector indexes are clearly separated from NL2SQL-only profiles.
AI Agents Interaction with selected Select AI Agent teams for task-oriented workflows. Agent tools are approved, least-privilege, and auditable.
Charts and explanations Charts from NL2SQL result sets plus generated SQL explanations and narrated output. Charts match result columns, and users can inspect SQL before trusting results.

Why it matters

Ask Oracle is useful when teams want a practical front end for Select AI without building a custom user interface first. It gives technical and non-technical users a way to try natural-language access to trusted database data, inspect generated SQL, create visual summaries, and test agent workflows from an APEX application that can be customized.

How to enable

Use a test workspace first. The sample app is intended to accelerate evaluation, but production use still requires normal APEX review, data-security review, and Select AI profile governance.

Step 1: Prepare Select AI

Configure Select AI prerequisites and create at least one AI profile. Scope profiles to the schemas and objects that the chatbot should use. 

-- Example pattern only. Use the provider and attributes approved for your environment.
BEGIN
  DBMS_CLOUD_AI.CREATE_PROFILE(
    profile_name => 'ASK_ORACLE_NL2SQL',
    attributes   => '{
      "provider": "oci",
      "credential_name": "OCI_GENAI_CRED",
      "object_list": [
        {"owner": "APP", "name": "ORDERS"},
        {"owner": "APP", "name": "CUSTOMERS"}
      ]
    }'
  );
END;
/
-- Set the active Select AI profile for the session.
BEGIN
  DBMS_CLOUD_AI.SET_PROFILE('ASK_ORACLE_NL2SQL');
END;
/

Step 2: Prepare optional RAG and agent assets

If you want RAG, create or select an AI profile with a vector index. If you want workflow automation, create or select a Select AI Agent or agent team with approved tools. 

-- Review profile metadata before assigning it as the Ask Oracle default.
SELECT profile_name,
       status,
       description
FROM   user_cloud_ai_profiles
ORDER  BY profile_name;
-- Review agent tool metadata before exposing an agent team through the app.
SELECT tool_name,
       description,
       status
FROM   user_cloud_ai_agent_tools
ORDER  BY tool_name;

Step 3: Import the Ask Oracle APEX application

Download the Ask Oracle sample app linked from the Oracle blog. In APEX App Builder, import the application, install supporting objects, and complete the standard import workflow.

  1. Open the target workspace in APEX App Builder.
  2. Choose Import.
  3. Upload the Ask Oracle application export file.
  4. Review application ID, parsing schema, and installation options.
  5. Install supporting objects.
  6. Run the application.

Step 4: Configure Ask Oracle settings

In the application settings, select default AI profiles and agent teams. Use separate profiles for chat, NL2SQL, and RAG when the data scope or model behavior differs.

Setting Recommended configuration
Default chat profile Use a profile intended for general LLM conversation.
Default NL2SQL profile Use a profile scoped to approved application tables and views.
Default RAG profile Use a profile with the correct vector index configured.
Default agent team Use an agent team with narrow tools and clear operational boundaries.

Test example

Test one capability at a time. Keep the first prompts simple so you can confirm profile routing, generated SQL, result shape, and chart behavior.

Test Prompt Expected result
Chat Summarize what this assistant can help with. The response comes from the selected chat profile without querying database tables.
NL2SQL Show total orders by month for the last six months. The app returns a result set and lets the user inspect the generated SQL.
Explain SQL Explain the generated query step by step. The app explains filters, grouping, and selected columns in plain language.
Chart Create a bar chart from the result grouped by month. The chart uses the NL2SQL result set and can be refined through UI controls or prompts.
RAG Answer a question that should use indexed documents. The response uses the selected RAG profile and its vector index.
Agent workflow Ask the selected agent team to perform a simple approved task. The workflow uses the configured agent and tools without exceeding permissions.

Validate the generated SQL directly when testing NL2SQL. This helps confirm that the profile is using the intended tables, predicates, and aggregation logic. 

-- Use the SQL displayed by Ask Oracle, then validate plan and row counts.
SELECT /*+ gather_plan_statistics */
       order_month,
       order_count
FROM   (
  -- Paste generated SQL here after review.
  SELECT TRUNC(order_date, 'MM') AS order_month,
         COUNT(*) AS order_count
  FROM   app.orders
  WHERE  order_date >= ADD_MONTHS(TRUNC(SYSDATE, 'MM'), -6)
  GROUP  BY TRUNC(order_date, 'MM')
)
ORDER  BY order_month;

FROM   TABLE(DBMS_XPLAN.DISPLAY_CURSOR(
         sql_id => NULL,
         cursor_child_no => NULL,
         format => 'TYPICAL +IOSTATS LAST'
       ));

Expected results

  • The Ask Oracle app imports into APEX and installs supporting objects successfully.
  • Settings show available AI profiles and agent teams for user selection.
  • Chat prompts use the selected LLM profile without requiring SQL knowledge.
  • NL2SQL prompts produce inspectable SQL and database result sets.
  • RAG prompts use profiles with vector indexes when document-grounded answers are required.
  • Charts can be created and refined from NL2SQL result sets.
  • Agent workflows execute only the tools and tasks approved for the selected agent team.

Operational checks

Area Check Reason
Security Limit AI profiles to approved schemas, views, and objects. Natural-language access should not expand data access beyond policy.
Transparency Keep generated SQL visible for NL2SQL results. Users and reviewers need to understand how answers were produced.
Governance Review prompt details, selected profiles, and selected agents. Prompt-level metadata supports troubleshooting and audit review.
Performance Review generated SQL with execution plans for expensive questions. Natural-language prompts can still generate SQL that needs tuning.
